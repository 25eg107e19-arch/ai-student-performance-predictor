# ai-student-performance-predictor
An ML-powered student performance prediction dashboard using Python and Streamlit.

🎓 AI Student Performance Predictor

🔗 Live Demo: "Open the AI Student Performance Predictor" (https://ai-student-performance-predictor-k8fu9rnxro6pz7wfvf8fco.streamlit.app/)

📌 About the Project

An interactive machine learning web application that estimates student exam scores using study habits and previous academic performance.

✨ Features

- Predict estimated exam scores
- Interactive sliders for student details
- Personalized study suggestions
- Model evaluation using MAE and R²
- Feature importance visualization

🛠️ Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Random Forest Regression

⚙️ How It Works

The application trains a Random Forest regression model on synthetic data and uses student inputs to estimate an exam score.

🚀 Run Locally

1. Clone this repository.
2. Install the dependencies:
   "pip install -r requirements.txt"
3. Run the application:
   "streamlit run app.py"

⚠️ Disclaimer

This project is an educational demonstration using synthetic data. Predictions have not been validated against real student records and should not be treated as reliable academic forecasts.
